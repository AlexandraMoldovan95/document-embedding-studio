Document Embedding Studio - Demo

A hands-on walkthrough of how the real Document Embedding Studio works, using one of three sample documents and fixed, pre-written results - nothing to install, nothing to set up. Pick a document, watch it get split into pieces and indexed, then search it and ask it questions, the same four steps as the real app, just with sample data standing in for the real processing (details on that further down the page).

🧪 Static demo - three sample documents, fixed chunks, no backend running and nothing uploaded anywhere. All three are written for this demo (not real-world files), so there's nothing to attribute and nothing borrowed. The search and the assistant below really read the sample text you pick, they just don't call a real embedding model or an LLM.

2 Chunks

Process the document above to see it split into overlapping windows - each chunk slightly repeats the tail of the one before it, which is what lets semantic search find an idea even when it falls near a chunk boundary.

3 Semantic search

This really scores the sample chunks above against what you type (by word overlap, not a trained embedding model) - try a suggestion or type your own question about the document.

4 Ask the assistant

The real app sends the matched chunks plus your question to an AI model, using your own OpenAI / Anthropic / Gemini key - you bring your own key, so nothing is billed to me - and the model writes the answer. For the curious: the real app behind this walkthrough runs on FastAPI (Python) and Next.js, with a local embedding model and a persistent ChromaDB vector database, all in Docker - infrastructure a free static host like this one can't run, which is why this page exists as a hands-on stand-in. All three sample documents above were written specifically for this demo, not sourced from anyone else's material.
